# Homing releases

Signed Android releases of **Homing**: privacy-first location sharing for family and friends, end-to-end encrypted.
The server can't read anyone's location. No account, e-mail or phone number. No Google Play Services.

## Install with Obtainium

1. Install [Obtainium](https://github.com/ImranR98/Obtainium).
2. Add app, source URL: `https://github.com/jsvdmeer/homing-releases`
3. Obtainium installs Homing and keeps it up to date.

Releases are signed with the same key every time; Android refuses an update signed with another key.
