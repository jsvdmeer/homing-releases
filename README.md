# Homing

Location sharing for family and friends, end-to-end encrypted. Android.

- Your location is encrypted on your phone; the server can't read it.
- Groups with an invite link or QR code; an admin approves every request.
- Live map with members, their trips, places with arrival notifications, battery and charging state.
- Pause sharing for everyone or for one group; others see "Paused", never an old location.
- Works without Google Play Services, including on GrapheneOS.
- Account to restore everything on a new phone: username, password and an authenticator app, passkey or backup codes.
